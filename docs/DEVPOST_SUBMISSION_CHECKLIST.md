# Gemini 3 Hackathon Submission Checklist (Devpost)

Source: https://gemini3.devpost.com/rules

## Key dates (Pacific Time)
- Submission Period: Dec 17, 2025 1:00 PM PT to Feb 9, 2026 5:00 PM PT
- Judging Period: Feb 10, 2026 9:00 AM PT to Feb 27, 2026 11:45 PM PT
- Winners Announced: On or around Mar 4, 2026 2:00 PM PT

## Must-have submission materials
- New project built during the contest period and uses the Gemini 3 API.
- Brief text write-up (~200 words) describing the Gemini integration and why it is central.
- Public project link (working demo or test build). If private, include credentials.
- Public code repository URL required if no AI Studio project link is provided.
- Demo video (public YouTube or Vimeo link):
  - Shows the project running on the target platform.
  - Not longer than 3 minutes (only first 3 minutes evaluated).
  - In English or with English subtitles.
- Testing access must be free and unrestricted through the end of the Judging Period.

## Project requirements
- Runs consistently on the intended platform and matches the demo and description.
- English language support at minimum (or provide English translation of materials).
- Disclose third-party SDKs/APIs/data used in the submission description.
- Team members must be added on Devpost; designate a representative if a team/org.
- Submission must be original and not infringe third-party IP or rights.
- No financial or preferential support from the Sponsor/Administrator before submission.
- If special hardware is required and not widely available, be prepared to provide access.

## Content restrictions
- No offensive, hateful, illegal, defamatory, or inappropriate content.
- No third-party ads, slogans, or logos implying sponsorship.
- No violations of privacy, publicity, or IP rights.

## Scoring criteria (Stage Two)
- Technical Execution: 40%
- Innovation/Wow Factor: 30%
- Potential Impact: 20%
- Presentation/Demo: 10%

## Afterlog-specific prep (recommended)
- Provide a test build (APK) that runs without extra setup steps.
- Ensure the demo video shows: capture, highlight selection, replay generation, subtitles.
- Include testing instructions (permissions, expected device model/OS).
- Include a safe testing path if API keys are required (demo mode or test key).
- Keep the public repo clean and up to date with the submission build.

## Submission modifications
- You can edit drafts before the submission deadline.
- After the submission period ends, changes are generally not allowed except for
  removing inappropriate or infringing content if requested.
