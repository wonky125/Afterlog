# AfterLog Release v1.2.0

## [1.2.0] - 2026-01-04

### Added
- **Cinematic UI**: Implemented a "Newspaper" style visual for the case reports.
- **EvidenceCard Component**: A modularized UI component for displaying visual evidence with metadata.
- **Real Data Simulation**: Added a debug mode to visualize reports using static JSON data (`gemini_audio_result.json`) and sample images.
- **Specialized Typography**: Integrated `Lora` and `Special Elite` fonts for a vintage detective feel.
- **Textured Backgrounds**: Added paper-textured backgrounds with customizable blending.

### Changed
- **Modularized Report Screen**: Refactored `ReportDetailScreen.kt` (reduced by ~400 lines) into separate components:
  - `CinematicNewspaperView`
  - `TimelineEventCard`
  - `EvidenceCard`
  - `ReportComponents`
- **ViewModel Enhancements**: Added `setMockData` to `GameResultViewModel` for testing purposes.

### Fixed
- Font size calculation error in `EvidenceCard` scale logic.
- Newspaper animation landing synchronization.
