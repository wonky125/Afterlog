# Pull Request: Gemini AI Integration (v1.1.0)

## 📝 Summary
This release integrates **Google Gemini API** to analyze game sessions (Video & Audio) and generate a "1920s Noir Investigative Journalist" report. It includes copyright safety mechanisms and a modular architecture for handling large media files.

## 🚀 Key Features
1.  **Noir Reporter Persona**:
    *   Generates articles in the style of "The Midnight Chronicle".
    *   Example output: *"The clock struck three when the first whisper echoed through the empty halls..."*
2.  **Multimodal Analysis**:
    *   **Video**: Extracts key frames to understand the visual scene.
    *   **Audio**: Uses **Gemini Files API** to upload and process large audio files (10min+) for detecting screams, dialogue, and monster names.
3.  **Copyright Safety Layer**:
    *   Automatically masks trademarked terms in the prompt.
    *   *Arkham* -> *The Dark City*, *Cthulhu* -> *The Ancient Horror*.
4.  **UI Updates**:
    *   Added "Analyze Game" button to Home Screen.
    *   Added Debug Controls (Start Service, Simulate Scream).

## 🛠 Technical Implementation
*   **`GeminiFilesApiClient.kt`**: New modular HTTP client for robust file uploading (resumable/multipart support via OkHttp).
*   **`GeminiRepository.kt`**: 
    *   Refactored to return `Pair<URI, MimeType>` for correct multimodal request construction.
    *   Optimized prompt engineering with JSON output enforcement.
*   **`HomeScreen.kt`**: Implemented permissions handling and service control logic using Compose.

## 🧪 How to Test
1.  **Build & Run** on a physical device (Emulator microphone support varies).
2.  **Permissions**: Grant Camera & Microphone permissions.
3.  **Capture**:
    *   Click **"Start Background Service"**.
    *   Make some noise or click **"Simulate Scream"**.
    *   Click **"Stop Service"**.
4.  **Analyze**:
    *   Click **"Analyze Game (Gemini)"**.
    *   *Note*: If no real recording exists, it will load verified Mock Data.

## ⚠️ Notes for Reviewers
*   **API Key**: Ensure `GEMINI_API_KEY` is set in your `local.properties`.
*   **Model**: Currently set to `gemini-2.5-flash` for development. Production will switch to `gemini-1.5-pro` or `gemini-3-pro`.
