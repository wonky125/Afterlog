# 📅 애프터로그(Afterlog) 개발 로드맵

## 1단계: 기반 구축 및 데이터 수집 (1~2주 차)
**목표**: 앱의 뼈대를 잡고, 게임 중 사진과 비명을 끊김 없이 수집하는 기능을 완성합니다.

| 주차 | 핵심 과제 | 상세 내용 |
| :--- | :--- | :--- |
| **1주 차** | **프로젝트 초기 설정** | • Hilt, Navigation, Room DB 등 기본 아키텍처 설정<br>• CameraX & Gemini API 연동 테스트<br>• 빈 화면 간 이동 확인 |
| **1~2주 차** | **백그라운드 수집 서비스** | • **Foreground Service**: 다른 앱 실행 중에도 수집 유지<br>• **Time-lapse**: 5초 간격 무음 촬영 (Preview-less)<br>• **Audio Trigger**: 80dB 이상 비명 감지 로직 구현 |
| **2주 차** | **로컬 저장소 연결** | • **Offline-first**: 수집된 사진/오디오 로그 Room DB 저장<br>• 데이터 유실 방지 구조 완성 |

## 2단계: Gemini AI 지능 부여 및 MVP 완성 (3~4주 차)
**목표**: 수집된 데이터를 분석하여 서사를 생성하고, 이를 시각화하는 핵심 루프를 완성합니다.

| 주차 | 핵심 과제 | 상세 내용 |
| :--- | :--- | :--- |
| **3주 차** | **Gemini 클라이언트 통합** | • **Gemini 1.5 Pro**: Google AI SDK 연동<br>• **Multimodal Prompt**: 이미지+오디오 전송 및 JSON 로그 수신<br>• **Persona**: 1920년대 수사 기자 컨셉 적용 |
| **4주 차** | **시네마틱 리포트 UI** | • **NewspaperView**: 신문 스타일의 결과 리포트 UI 구현 |
| **4주 차** | **기본 영상 합성** | • **MediaMuxer**: 사진 시퀀스 + TTS 나레이션 = MP4 합성<br>• **MVP Checkpoint**: 촬영 -> 분석 -> 리포트 -> 재생 (단일 기기 완결) |

## 3단계: 고도화 및 와우 포인트 (5주 차)
**목표**: 심사위원에게 강한 인상을 남길 수 있는 디테일과 사용자 경험을 개선합니다.

| 주차 | 핵심 과제 | 상세 내용 |
| :--- | :--- | :--- |
| **5주 차** | **디테일 및 동기화** | • **Sync-Play**: 리포트 로그 클릭 시 해당 영상 시점으로 이동<br>• **UI/UX Polishing**: 양피지 텍스처, 워터마크, 세리프 폰트 적용 |
| **5주 차** | **(Optional) 멀티 디바이스** | • Firebase 활용 호스트-게스트 데이터 동기화 (여유 시) |

## 4단계: 최종 테스트 및 제출 준비 (6주 차)
**목표**: 안정성을 점검하고 심사 기준에 맞춘 제출물을 제작합니다.

| 주차 | 핵심 과제 | 상세 내용 |
| :--- | :--- | :--- |
| **6주 차** | **최종 테스트** | • **Long-play**: 3시간 연속 구동 안정성 및 배터리 테스트 |
| **6주 차** | **제출물 제작** | • **Demo Video**: 3분 이내 임팩트 영상 (영어 자막 필수)<br>• **Final Submission**: GitHub 정리, 아키텍처 다이어그램, APK |

## 💡 전략적 핵심 팁 (Strategic Tips)

1. **할루시네이션 방지 (Accuracy)**
   - Gemini에게 오디오에서 추출된(STT) 키워드를 힌트로 제공하여 "없는 사건"을 지어내는 환각을 방지합니다.

2. **휴먼-인-더-루프 (UX)**
   - AI가 생성한 로그를 사용자가 직접 **수정(Edit)**할 수 있게 하여, 완벽하지 않은 AI 성능을 UX로 커버합니다.

3. **비용 및 토큰 최적화 (Cost)**
   - **Resizing**: 사진은 전송 전 리사이징하여 토큰 비용 절약.
   - **Sampling**: 전체 영상 대신 '하이라이트 구간' 위주로 선별 전송.

> 이 로드맵은 "기사의 초안(MVP)을 빠르게 작성하고, 남은 시간 동안 문장(디테일)을 다듬는" 전략으로 진행됩니다.
